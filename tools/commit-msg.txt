Android 2.2 music player: basic features and APK build

Music player for Android 2.2 (Froyo, API level 8) with an installable APK.

Features
- Scans a directory (default /sdcard/Music, recursing into subdirectories)
- Lists title/artist/duration, highlighting the currently loaded track
- Play/pause, previous/next, draggable seek bar with live time readout
- Audio focus handling: pauses on interruption, resumes afterwards, ducks volume
- Formats: mp3/m4a/aac/wav/ogg/flac/mid/amr/3gp/mp4

Build pipeline
aapt (R.java + resources) -> javac (-source/-target 1.6, -bootclasspath android.jar)
-> dx (classes.dex) -> aapt add -> apksigner (v1 only) -> zipalign

Compatibility notes
- Java 6 bytecode: class files are major version 50, verified per-class with dexdump
- v1 (JAR) signing only: APK Signature Scheme v2 arrived in Android 7.0 and is not
  understood by 2.2, so v2 is explicitly disabled
- No AndroidX/support library: depends only on android.jar (API 8), APK is 27 KB
- Vector/adaptive icons need a higher API, so one PNG per density is generated
- dx.bat and apksigner.bat are bypassed: both locate Java through find_java.bat,
  which build-tools 25 no longer ships, so they exit silently with status 0 without
  doing any work. The build calls java -jar lib/dx.jar and lib/apksigner.jar directly.

Verification
- Static: minSdkVersion=8, permissions, resources, dex class list, signature and
  zipalign all pass
- Real device: installed on an Android 2.2 handset; basic features confirmed working

The toolchain is not tracked (see .gitignore): tools/jdk, tools/sdk, tools/mingit and
tools/downloads total about 630 MB. Run tools/fetch_toolchain.ps1 after cloning.
